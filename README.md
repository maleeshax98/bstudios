# bstudios

High-end photography and cinematic videography studio web application framing raw moments into timeless art, built with Next.js, Tailwind CSS v4, shadcn/ui, and GSAP.

## Getting Started

First, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
